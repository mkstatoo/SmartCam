# کارآگاه دوربین (Detective Camera)

اپلیکیشن موبایل (Flutter، اندروید و iOS) که تصویر دوربین‌ها را می‌گیرد، **روی خود گوشی** تحلیل می‌کند و در صورت **حرکت، آتش یا دود** به کاربر هشدار می‌دهد (آژیر، لرزش، اعلان سیستمی، صفحهٔ هشدار تمام‌صفحه).

## قابلیت‌ها

| بخش | توضیح |
|---|---|
| منابع تصویر | RTSP / RTMP / HLS (با media_kit)، MJPEG روی HTTP، عکس لحظه‌ای HTTP، دوربین همین گوشی |
| کشف دوربین | ONVIF (WS-Discovery + دریافت خودکار آدرس RTSP، با احراز هویت دیجست) |
| احراز هویت | Basic و Digest برای HTTP؛ نام کاربری/رمز در حافظهٔ امن سیستم‌عامل |
| تشخیص | حرکت (پس‌زمینهٔ تطبیقی، فیلتر تغییر نور)، آتش (رنگ + سوسوزدن)، دود (آزمایشی) |
| ناحیهٔ پایش | رسم ناحیهٔ «فقط پایش کن» و «نادیده بگیر» روی تصویر |
| هشدار | آژیر تکرارشونده تا خاموش‌کردن (+ توقف خودکار)، لرزش، اعلان، صفحهٔ هشدار با عکس |
| پایداری | اتصال مجدد خودکار، اعلام قطع/وصل دوربین، سرویس پیش‌زمینه (اندروید)، wakelock |
| رویدادها | عکس همراه کادر ناحیهٔ تشخیص، فهرست و تأیید «دیدم» |

## راه‌اندازی

```bash
# ۱) ساخت اسکلت پلتفرم‌ها (یک بار) در پوشهٔ همین پروژه
flutter create . --org ir.detective --project-name detective_camera --platforms android,ios

# ۲) تنظیمات پلتفرم: محتوای این دو فایل را در مانیفست و Info.plist اضافه کنید
#    platform_snippets/AndroidManifest.additions.xml
#    platform_snippets/iOS.Info.plist.additions.xml
#    (و minSdk اندروید = 24، iOS = 13)

# ۳) وابستگی‌ها
flutter pub get          # در صورت ناسازگاری نسخه: flutter pub upgrade --major-versions

# ۴) اجرا روی گوشی واقعی
flutter run
```

> `flutter create .` فایل‌های `lib/`، `pubspec.yaml` و `assets/` موجود را دست نمی‌زند؛ اگر `lib/main.dart` را جایگزین کرد، نسخهٔ این پروژه را برگردانید.

## معماری

```
lib/
  core/        هستهٔ تشخیص (Dart خالص، بدون Flutter؛ تست‌پذیر در خط فرمان)
    frame.dart, zone.dart, motion_detector.dart, fire_smoke_detector.dart,
    detection_engine.dart (تأیید چندفریمی + زمان خنک‌شدن),
    mjpeg_parser.dart, onvif.dart, sha1.dart
  sources/     منابع تصویر: stream (media_kit), mjpeg, snapshot, phone camera
  services/    CameraMonitor (هر دوربین)، MonitorManager، آلارم، اعلان، پس‌زمینه، ذخیره‌سازی، ONVIF
  models/      CameraConfig, DetectionEvent, AppSettings
  ui/          خانه، ویرایش دوربین، ویرایش ناحیه، رویدادها، تنظیمات، صفحهٔ هشدار
```

جریان داده: `FrameSource → (فریم ۳۲۰px) → DetectionEngine → DetectionSignal → CameraMonitor → MonitorManager → آلارم/اعلان/ذخیره`.

## الگوریتم‌ها (و محدودیت‌هایشان)

- **حرکت:** خاکستری ← محو ۳×۳ ← اختلاف با پس‌زمینهٔ تطبیقی ← بلوک‌های ۸×۸ ← بزرگ‌ترین توده. اگر بیش از ۵۵٪ پیکسل‌ها همزمان تغییر کند، تغییر نور/اکسپوژر فرض می‌شود و حرکت اعلام نمی‌شود. سایه و برگ درخت می‌توانند هشدار کاذب بدهند؛ از ناحیهٔ «نادیده بگیر» و حساسیت استفاده کنید.
- **آتش:** پیکسل‌هایی با رنگ شعله که در ۸ فریم اخیر حداقل دو بار روشن/خاموش شده‌اند. جسم نارنجی ثابت یا ماشین نارنجی در حال عبور آتش حساب نمی‌شود. آتشی که در تصویر ثابت و بدون سوسو دیده شود (یا نور بسیار کم/خیلی دور) ممکن است تشخیص داده نشود.
- **دود:** لکهٔ خاکستری کم‌اشباع که نسبت به پس‌زمینهٔ کند تغییر کرده، چند فریم پایدار مانده و کوچک نمی‌شود. **آزمایشی است** و با لباس خاکستری، مه یا بخار می‌تواند اشتباه کند.
- هیچ مدل یادگیری ماشین‌ای (مثل YOLO/TFLite) در این نسخه نیست؛ تشخیص شخص/خودرو/حیوان و تشخیص دقیق‌تر آتش و دود قدم بعدی طبیعی است (نیازمند فایل مدل و افزودن `tflite_flutter`).

**این برنامه جایگزین دتکتور دود/حرارت استاندارد نیست.**

## اعتبارسنجی

```bash
dart run tool/run_core_tests.dart     # ۴۶ تست روی هستهٔ تشخیص، MJPEG، ONVIF، SHA-1
```

تست‌ها فریم‌های مصنوعی تولید می‌کنند (نویز سنسور، جسم متحرک، تغییر نور، شعلهٔ سوسوزن، جسم نارنجی ثابت/متحرک، لکهٔ دود در حال رشد و …) و درستی رفتار هسته را می‌سنجند. درستی تشخیص روی **فیلم واقعی دوربین شما** باید جدا ارزیابی شود.

## نکات اجرایی

- **پردازش روی گوشی است:** برای کاهش مصرف CPU از زیرجریان (sub-stream) با رزولوشن کم (۶۴۰×۳۶۰ یا کمتر) استفاده کنید. در ONVIF همین کار خودکار است.
- **iOS** اجازهٔ پردازش دائمی تصویر در پس‌زمینه را نمی‌دهد؛ برای پایش واقعی برنامه باید باز و صفحه روشن (wakelock) بماند. اندروید با سرویس پیش‌زمینه و معافیت از بهینه‌سازی باتری (در تنظیمات برنامه) پایدارتر است.
- برای شنیده‌شدن آژیر، صدای رسانه/آلارم گوشی را بلند نگه دارید.
- دوربین‌های `https` با گواهی خودامضا ممکن است در حالت MJPEG/Snapshot خطای گواهی بدهند؛ از `http` یا RTSP استفاده کنید.
